# Contributing

PRs are welcome, including ones written with AI tools.

- For anything bigger than a small fix, open an issue first so we can agree the approach before you put time in.
- Keep each PR to one change and say how you tested it. `cargo test` should pass in `optimiser/` and `autoscaler/`. Both need OR-Tools, see the README.
- If AI wrote a large part of the PR, say so in the description. That's fine, but you need to understand the change well enough to answer review questions on it.
- Commit messages are conventional commits with a capitalised subject, e.g. `docs: Fix typo in README`.

## My own changes

I write most of my own changes to this repo by hand, as coding practice. That's a choice for me, not a rule for contributors.
